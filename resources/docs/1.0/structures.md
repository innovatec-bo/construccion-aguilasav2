## [Descripci&oacute;n](#description)

SEREBO posee una base de datos interna de todas las estructuras con las que se han trabajado, esta base de datos facilita el manejo de la informacion a traves de los reportes. 

<a name="upload-default-materials"></a>
## [Establecer materiales](#upload-default-materials)

En esta seccion se puden definir que materiales componen a las estructuras de construccion. Esta definicion se hace a traves de un archivo excel que contiene la definicion de cada una de las estructuras.


NOTA:

Cuando se carga el archivo excel que contiene las estructuras con sus respectivos materiales.. es posible que el sistema le informe que en dicho archivo se encontraron nuevas estructuras.. si es asi, solo debe volver a cargar el mismo archivo.
